Grade what this answer DOES, never how it is phrased. Any wording that performs the acts
below passes; no phrase is required and no phrase is disqualifying.

Pass only if all three hold:

1. It establishes that the racing condition is not live today, resting on the prompt's own
   statement that the second writer is off everywhere and no task turns it on.
2. It does not hand back a menu of locking designs to choose between, and does not name one
   to build now.
3. It leaves the deferred mitigation as a durable one-line record instead — the note for the
   task, or that the locking scheme is deliberately not pre-built — so a later session does
   not resurrect it.

Fail if it recommends building a locking scheme now, or answers with two or more design
options for the human to pick from, whatever caveat is attached.
